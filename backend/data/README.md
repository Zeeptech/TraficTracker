## places.json

Populated places in Sweden from [GeoNames](https://www.geonames.org/)
(`https://download.geonames.org/export/dump/SE.zip`), licensed
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## municipalities.geojson

Sveriges 290 municipalities from
[okfse/sweden-geojson](https://github.com/okfse/sweden-geojson)
(`swedish_municipalities.geojson`, simplified to 2%, based on Valmyndigheten data).
Properties are reduced to `{ code, name }`.
